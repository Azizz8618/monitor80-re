# Монитор-80 (monitor80-re)

Восстановление исходных текстов операционной системы **Монитор-80** (ИАЭ им. Курчатова), созданной на базе мониторной системы «Дубна» из ОИЯИ.

Цель проекта — восстановить возможность пересобирать дистрибутив «Монитора-80» с возможностью внесения исправлений и изменений.

Направления работы:
* воссоздание исходных текстов служебных подпрограмм из постоянной библиотеки
* дизассемблирование и деконструкция стандартных статических оверлеев
* дизассемблирование начального загрузчика и динамического загрузчика
* выяснение механизма формирования постоянной библиотеки

Для работы требуются: `dispak`, `besmtool` (из besm6/dispak) и `dtran`, `disbesm6` (из leobru/dispak-tools).

## Инструменты

| Инструмент | Назначение | Формат |
|------------|------------|--------|
| `asm.pl` | Ассемблирование (.asm/.masm → .orig) | Perl |
| `disas.pl` | Дизассемблирование (.dis) | Perl |
| `cosy2txt` | Конвертер COSY в текст (ГОСТ 10859) | C++ |
| `ovl2bin` | Конвертер оверлеев в бинарный формат | C |
| `encoding.cpp` | Обработка кодировок (ГОСТ 10859) | C++ |
| `besmtool` | Дамп/запись данных на виртуальные диски | Программа |
| `dispak` | Эмулятор трансляторов ОС Диспак | Программа |
| `disbesm6` | Дизассемблер БЭСМ-6 | Программа |

## Формат файлов

* `.asm` — исходные тексты (ассемблер БЭСМ-6, формат DTRAN/ASSEM)
* `.masm` — макроассемблерные исходники (МАДЛЕН)
* `.dtr` — файлы описания модулей (для DTRAN)
* `.sym` — таблица символов
* `.dis` — результат дизассемблирования (cosy2txt)
* `.orig` — оригинальный результат дизассемблирования

## Сборка

```bash
# permanent (ядро) —_REGION=80
 cd permanent && export WORKVOL=80 && make

# inputcal —输入/check
 cd inputcal && export WORKVOL=80 && make

# tools — утилиты
 cd tools && make

# utility
 cd utility && make
```

Результат: файлы `.diff` проверяют совпадение `.orig` с `.dis`.
Если diff пустой — модуль восстановлен корректно.
