# Справочник команд Монитора-80

Для ИИ-агентов. Основан на исходниках `~/Yandex.Disk/monitor80-re/permanent/`.

---

## 1. Общие сведения

**Монитор-80** — операционная система ИАЭ им. Курчатова для БЭСМ-6,
созданная на базе мониторной системы «Дубна» из ОИЯИ.

**Отличия от ОС «Дубна»:**
- Отказ от ненужных трактов МБ
- Упрощённый ввод заданий (карточный)/n- Модификации в стандартных программах (EXECUT, IOCONT, MONREAD и др.)
- Собственные модули: CHEKJOB, INPUTCAL, MODULER, REDACT

**Основные компоненты:**

| Компонент | Файл | Назначение |
|-----------|------|------------|
| Резидент Монитора | `mon%itor.asm` | Ядро системы, планировщик |
| Командный процессор | `star%.masm` | Обработка системных карт |
| Модуль 2-й резидент | `monitor_.asm` | Загрузка программ, управление |
| Инициализация | `inputcal/inputstar.asm` | Управляющая программа задачи ввода |
| Входной контроль | `chekjob/chekjob.asm` | Проверка заданий |

## 6. Системные карты — подробное описание

### 6.1. Управление листом и выводом

**`*FULL LIST`** — Полный листинг. Все команды (включая системные)
печатаются в выходном файле.

**`*NO LIST`** — Подавление листинга. Выводятся только ошибки.

**`*STANDARD`** — Стандартный режим (по умолчанию). Печатаются
машинные команды и заголовки модулей.

**`*1`** — Переключение на новый лист (новая страница вывода).

### 6.2. Управление загрузкой

**`*NO LOAD`** — Подавление загрузки скомпонованных модулей.
Полезно при отладке: модули компонуются, но не загружаются в память.

**`*SYSTEM`** — Системная загрузка. Модуль загружается как системный
(адрес 0 и выше).

**`*PERMANENT`** — Загрузка из постоянной библиотеки.
Команда выполняет: `LOADF` → `LOADANGO` → чтение модуля
с постоянного диска.

**`*TEMPO`** — Загрузка из временной библиотеки.
Аналогична `*PERMANENT`, но ищет модуль во временной библиотеке.

### 6.3. Режимы работы

**`*ADDRESS`** — Режим адресации. Устанавливает бит 37 в `*REGIM//`.

**`*NO STOP`** — Без останова на ошибках. Устанавливает бит 38.

**`*NO BINARY`** — Без бинарного вывода. Устанавливает бит 39.

**`*OLD PUNCH`** — Режим старой перфоленты. Устанавливает бит 40.

**`*SUPER`** — Супервизорский режим. Устанавливает биты 43+48 в `*REGIM//`.

**`*NO SUPER`** — Пользовательский режим. Сбрасывает биты 43+48.

**`*DEBUG`** — Режим отладки. Устанавливает бит 42.

**`*NO DEBUG`** — Выключить отладку. Сбрасывает бит 42.

**`*PUNCH`** — Разрешить перфоленту. Устанавливает `PUNCHFL*`.

**`*NO PUNCH`** — Запретить перфоленту. Сбрасывает `PUNCHFL*`.

**`*OPTIM`** — Режим оптимизации. Сбрасывает бит 7.

**`*NO OPTIM`** — Без оптимизации. Устанавливает бит 7.

**`*NO CHECK`** — Без входного контроля. Переход через `DOS` → `SETFTN*`.

**`*MACRO`** — Режим макросов. Устанавливает бит 48 в `MACRO*`.

**`*NO MACRO`** — Без макросов. Сбрасывает бит 48.

### 6.4. Управление памятью

**`*LHEAP <число>`** — Установка размера кучи.
Вызывает `PARAMT*` для установки параметров.
Формат: `*LHEAP <число>` (число — в листах).

### 6.5. Управление каталогом

**`*CATAL`** — Операции с каталогом.
Вызывает `LOADCALL` с программой `CATALOG*`.

**`*EXCLUDE`** — Исключение модуля из каталога.
Вызывает `LOADCALL` с программой `LIBDELET`.

**`*LIBPUNCH`** — Перфолента библиотеки.
Вызывает `LOADCALL` с программой `LIBRPN*`.

**`*LIBLIST`** — Листинг библиотеки.
Вызывает `LOADCALL` с программой `LIBLIS`.

### 6.6. Программирование

**`*CALL <имя>`** — Вызов программы из постоянной библиотеки.
Формат: `*CALL <имя>` или `*CALL : <имя> <параметры>`.
Вызывает `GIVCALL*` для загрузки и запуска.

**`*CALL : <имя> <параметры>`** — Вызов программы с параметрами.
Параметры передаются через `MONCARD*`.

**`*EXECUTE`** — Выполнение программы с сохранением обменного листа.
Вызывает `EXECUT` → `BLEXPRIN` → `MONITOR*+3`.

**`*END FILE`** — Конец файла задания.
Вызывает `STOP*` → выход из системы.

**`*READ <vol>`** — Чтение с диска/тома.
Вызывает `READVOLK` для чтения данных.

**`*READ: <vol>`** — Чтение с параметрами.

**`*EDIT`** — Редактирование.
Вызывает `REDACT*` или `EDIT***`.

**`*EDIT: <vol>`** — Редактирование с томом.
Вызывает `READVOLK` → редактирование.

**`*MAIN`** — Основная программа.
Вызывает `GIVCALL*` для загрузки основной программы.

**`*NAME <имя>`** — Имя текущего модуля.
Устанавливает имя модуля для компоновки.

## 8. Механизм обработки системных карт

### 8.1. Поток выполнения

```
Ввод карты (MONREAD*)
    ↓
Разбор команды (IDENT6)
    ↓
Поиск в таблице SWITCH
    ↓
Переход на обработчик
    ↓
CHECKMORE → следующая карта
```

### 8.2. Таблица SWITCH (star%.masm, строки 310-410)

Таблица содержит пары: `ISO,6H<имя>` + `UJ,обработчик`.

Обработка:
1. `MONREAD*` читает карту в `MONCARD*`
2. `IDENT6` сравнивает первые 6 символов с записями таблицы
3. При совпадении — переход на соответствующий обработчик
4. Если нет совпадения — проверяется тип карты:
   - `GIVLIBR*` → поиск в библиотеке
   - `GIVSERV*` → поиск в служебных
   - `GIVTRAN*` → поиск транслятора
   - `LOADCALL` → загрузка и запуск

### 8.3. Формат системной карты

```
*ИМЯ     [параметры...]
```

Где:
- `*` — начало системной карты
- `ИМЯ` — имя команды (6 символов)
- `параметры` — дополнительные данные

## 9. Формат входного задания

### 9.1. Структура задания

```
<паспорт>        — идентификация задачи
<системные карты> — управление компиляцией
<данные>          — исходный код
<терминатор>      — конец задания
```

### 9.2. Паспорт задачи

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
```

### 9.3. Пример задания

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
*ASSEM
S 1000
C 012 032 1000
C 011 031 1001
E
*END FILE
```

### 9.4. Терминатор

- `финиш` или `FINISH` — конец задания
- `END` — конец модуля
- `ЕКОНЕЦ` — конец файла

### 10.2. Формат обмена

Обмен данными осуществляется через:
- **Обменный лист** (address 43B)
- **Буфер ввода/вывода** (адрес 47B)
- **Дескриптор** (LUN, формат, адрес)

## 13. Примеры использования

### 13.1. Трансляция Ассемблер

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
*ASSEM
S 1000
C 012 032 1000
C 011 031 1001
E
*END FILE
```

Запуск: `dispak -p my_task.txt`

### 13.2. Трансляция Фортран

```
ШИФР 410301^
ОЗУ 512K^
ВХО 1^
ВРЕ 001000^
START 1000^
E
*FORTRAN
<код на Фортране>
*END FILE
```

### 13.3. Вызов программы из библиотеки

```
*CALL : PROGRAMX param1 param2
```

### 13.4. Редактирование

```
*EDIT OLD 2053
<данные для редактирования>
*END FILE
```

### 13.5. Просмотр содержимого диска

```bash
# Список файлов на диске 2053
besmtool list 2053

# Просмотр паспортов задач
besmtool pass 2053

# Дамп зоны 0677
besmtool dump 2053 --start=0677 --length=1
```

## 14. Кодировка ГОСТ 10859

Основная кодировка БЭСМ-6:

| Символ | Код (6-бит) | Описание |
|--------|-------------|----------|
| пробел | 00 | Пробел |
| А-Я | 01-32 | Кириллица |
| 0-9 | 60-71 | Цифры |
| + | 73 | Плюс |
| - | 74 | Минус |
| * | 72 | Звёздочка |
| / | 75 | Косая черта |

## 15. Ошибки и диагностика

| Сообщение | Описание |
|-----------|----------|
| `***** <имя> IS ABSENT` | Модуль не найден в библиотеке |
| `WRONG USE OF SYSTEM CARD` | Неправильное использование системной карты |
| `ILLEGAL SYSTEM CARD` | Недопустимая системная карта |
| `ОШИБКИ В КАРТЕ '47'` | Ошибка в карте паспорта |
| `HET MECTA HА МБ'12'` | Нет места на барабане |
| `СЕРЬЕЗН=N` | Количество серьёзных ошибок |
| `NO *END FILE` | Отсутствует терминатор |
