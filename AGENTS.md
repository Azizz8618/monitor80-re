# AGENTS.md — Инструкции для ИИ-агента

## 0. Общая цель

Проект `monitor80-re` — восстановление исходных текстов операционной системы **Монитор-80** (ИАЭ им. Курчатова) через дизассемблирование и корреляцию с сохранёнными исходниками ОС «Дубна».

**Цель агента:** содействовать восстановлению исходных текстов модулей Монитора-80, анализировать и исправлять ошибки дизассемблирования, ассемблирования и проверки через diff.

## 3. Формат исходников

### 3.1. Формат ассемблера БЭСМ-6

Исходные тексты используют формат ассемблера БЭСМ-6 с расширениями:

- `/` — конец строки (разделитель)
- `,EQU,` — макрос эквивалентности
- `,LC,` — локальный счётчик (перемещение)
- `,SUBP,` — внешняя ссылка на подпрограмму
- `,NAME,` — имя модуля
- `,PC,` — начальный адрес (программный счётчик)
- Метки через `:` — формат `METKA: ,指令, OPERAND`

### 3.2. Формат DTRAN

- `*NAME` — начало имени модуля
- `*LIBRA:2` — библиотека
- `*COPY:1,270000,600000` — копирование данных
- `*CALL DTRAN(modname)` — вызов транслятора
- `*END FILE` — конец файла

### 3.3. Кодировка

- Основная кодировка: UTF-8
- Кириллица: ГОСТ 10859 (БЭСМ-6)
- Конвертация: `cosy2txt` (COSY → текст)

## 5. Типовые задачи

### 5.1. Добавление нового модуля

1. Найти объектный модуль (`.b6` или дамп диска)
2. Дизассемблировать: `disas.pl -vol 80 modname`
3. Создать `.asm` файл с восстановленным исходником
4. Добавить в Makefile
5. Собрать: `make`
6. Проверить: `diff modname.orig modname.dis`

### 5.2. Исправление модуля

1. Внести изменения в `.asm`
2. Собрать: `make`
3. Проверить: `diff modname.orig modname.dis`
4. Если diff пустой — модуль восстановлен корректно

### 5.3. Анализ сообщений об ошибках

- `*****`, `СЕРЬЕЗН=` — ошибки трансляции
- `СЕРЬЕЗН=0` — успех
- `*** modname IS ABSENT` — модуль не найден

## 6. Формат дампов

- `besmtool dump VOL --start=ADDR --length=LEN --to-file=FILE` — дамп диска в файл
- `besmtool dump VOL --length=LEN --to-file=/dev/stdout` — дамп в stdout
- `cosy2txt` — конвертация дампа в текстовый формат

## 7. Сравнение (diff)

```bash
# Сравнение дизассемблированного файла с исходником
diff -C 3 modname.orig modname.dis

# Проверка через Makefile
cd permanent && make
```

## 8. Правила для агента

### 8.1. Перед редактированием

1. Прочитать текущую версию файла (агента Cline)
2. Понять формат (ассемблер БЭСМ-6 или DTRAN)
3. Использовать команды `asm.pl` для проверки

### 8.2. При анализе ошибок

1. Читать `debug.txt` (если есть) или вывод make
2. Проверять `dispak` лог (формат: `dispak -l *.b6`)
3. Использовать `disas.pl` для обратного дизассемблирования

### 8.3. Формат отчёта

