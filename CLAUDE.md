# .clinerules — Правила для проекта monitor80-re

## Общие правила

1. **Перед работой** — прочитать `README.md` (структура), `AGENTS.md` (инструкции).
2. **Инструменты** — использовать только `asm.pl`, `disas.pl`, `cosy2txt`, `besmtool`, `dispak`, `disbesm6`.
3. **Формат исходников** — `.asm` (ассемблер БЭСМ-6), `.masm` (МАДЛЕН), `.dtr` (DTRAN).
4. **Кодировка** — UTF-8, кириллица — ГОСТ 10859.

## Правила сборки

- **permanent/** — `cd permanent && make` (export WORKVOL=80)
- **inputcal/** — `cd inputcal && make` (export WORKVOL=80)
- **tools/** — `cd tools && make`
- **utility/** — `cd utility && make`
- **Все сборки** — через `disas.pl` и `asm.pl` (Perl-скрипты)

## Правила сравнения (diff)

- После сборки проверять `diff -C 3 modname.orig modname.dis`
- Если diff пустой — модуль восстановлен корректно
- Если diff не пустой — нужна ручная проверка

## Правила Git

- Не коммитить без разрешения пользователя
- Не пушить без явного указания
- Использовать `git add .` (не `git add *`)

## Правила работы с файлами

- Не использовать `cat` для больших файлов (>1000 строк) — использовать `head`/`tail`
- Не перезаписывать файлы без необходимости
- Не создавать файлы в корне проекта (кроме README.md, AGENTS.md, .clinerules)
- Использовать UTF-8 для всех текстовых файлов

## Правила работы с Git

- Коммиты делать только по требованию пользователя
- Не пушить в upstream (редактировать можно только в forks)
- Использовать `git status` перед коммитом
- Использовать `git diff` для проверки изменений

## Запрещено

- Изменять формат исходников (форматirling)
- Изменять Makefile без необходимости
- Использовать `rm -rf` для удаления файлов
- Использовать `sudo` без необходимости
- Запускать долгие операции без проверки

## Правила отчётов

- Все отчёты — в формате Markdown
- Использовать таблицы для структурированной информа��ии
- Использовать списки для порядка выполнения

## Правила работы с файлами

- `.asm` — исходные тексты (ассемблер БЭСМ-6)
- `.masm` — макроассемблерные исходники (МАДЛЕН)
- `.dtr` — файлы описания модулей (для DTRAN)
- `.dis` — результат дизассемблирования
- `.orig` — оригинальный результат дизассемблирования

## Правила обновления

- Перед любым изменением проверять Git статус
- Не изменять файлы без обновления README.md
- Использовать короткие коммиты с описанием изменений

## Правила безопасности

- Не использовать `sudo`
- Не удалять файлы без подтверждения
- Не менять права доступа к файлам
- Не использовать `rm -rf`
